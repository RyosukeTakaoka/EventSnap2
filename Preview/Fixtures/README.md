# Fixture写真の差し替え

スクリーンショット撮影モードで使う写真は、次の優先順位で決まります。

1. **アプリバンドル内の `preview-photo-01.jpg` 〜 `preview-photo-18.jpg`**（実写）
2. 見つからない番号は **手続き生成のプレースホルダ**（`PreviewImageFactory`）

## ⚠️ App Store提出前に必ず実写へ差し替えてください

プレースホルダは抽象的なグラデーション画像です。サムネイルサイズでは
「写真のように」見えますが、実際のイベント写真ではありません。
このまま提出すると、アプリの価値がまったく伝わりません。

## 差し替え手順

1. 18枚のJPEGを用意する（縦位置推奨。横位置が混ざっても中央クロップされます）
2. `preview-photo-01.jpg` … `preview-photo-18.jpg` にリネームする
3. Xcodeで **EventSnap2ターゲットのリソースとして追加**する
   （Target Membership に `EventSnap2` のチェックが入っていること）
4. 一度アプリを削除するか、`PreviewImageFactory.version` を上げてから再ビルドする
   （生成済み画像がCachesにキャッシュされているため）

対応拡張子は `.jpg` / `.jpeg` / `.png` です。

## グリッド上の並び

`preview-photo-01` が最新（グリッド左上）、`preview-photo-18` が最も古い
（右下）になります。**一番良い写真を 01〜06 に置いてください。**
1枚目のスクリーンショットで確実に見えるのは最初の4〜5行です。

`preview-photo-04.jpg` は**カメラ画面の背景**にも使われます
（`PreviewFixtureLoader.cameraBackgroundIndex`）。カメラ越しに見えていて
自然な、人物が写った横長寄りの写真が向いています。

## タイムカプセルのロック枠になる番号

シーンによって、どの番号がロック（砂時計）表示になるかが変わります。

| シーン | ロックされる番号（1始まり） |
| --- | --- |
| `albumGrid` ほか | 08, 17 |
| `timeCapsule` | 01, 03, 04, 06, 07, 09, 12 |

ロックされた枠は画像が表示されないため、**実写を活かしたい写真は
`timeCapsule` シーンでロックされない番号（02, 05, 08, 10, 11, 13〜18）に
置く**と、両方のスクリーンショットで有効に使えます。

## 権利について

App Storeのスクリーンショットは公開物です。写っている人物全員から
掲載の同意を得た写真だけを使ってください。ストックフォトを使う場合は
アプリストア掲載が許諾されているライセンスかを確認してください。
